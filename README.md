# 📊 Product Intelligence Dashboard

An AI-powered Product Analysis and Search Intelligence platform built using **Python**, **Streamlit**, and **SerpAPI** to monitor product trends, extract real-time search insights, and generate interactive analytical reports.

---

## 🚀 Features

- 🔍 Real-time Google Search Analysis
- 📈 Product Trend Monitoring
- 🤖 AI-Powered Search Intelligence
- 📊 Interactive Dashboard Visualization
- ⚡ Automated Data Extraction
- 📱 Responsive User Interface
- 📉 Search Result Analytics
- 🌐 Streamlit Web Deployment

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Backend:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn
- **Visualization:** Matplotlib, Seaborn
- **API Integration:** SerpAPI
- **Deployment:** Streamlit Cloud

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/product-analysis.git
```

### Navigate to Project Folder

```bash
cd product-analysis
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

---

## 📦 Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Application

```bash
streamlit run app.py
```

---

## 🔑 API Configuration

Create a `.streamlit/secrets.toml` file:

```toml
SERPAPI_KEY = "YOUR_API_KEY"
```
